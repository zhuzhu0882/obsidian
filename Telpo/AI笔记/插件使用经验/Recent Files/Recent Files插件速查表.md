## 1. 基本信息

- 名称：Recent Files
- ID：`recent-files-obsidian`
- 版本：1.7.7
- 作者：Tony Grosinger
- 平台：桌面端 / 可能支持移动端
- 分类：任务与工作流管理

## 2. 你最应该先做的事

1. 打开设置页看插件选项
2. 打开命令面板搜索插件名称
3. 对照本地配置键确认当前 vault 已启用的能力
4. 结合同目录的示例页试用

## 3. 本地可见配置项

- `recentFiles`
- `omittedPaths`
- `omittedTags`
- `updateOn`
- `omitBookmarks`

## 4. 用例速览

- 快速回到最近编辑过的文件
- 减少来回找文件的成本

## 5. 信息来源

- `manifest.json`
- `data.json`
- manifest 未提供 helpUrl
