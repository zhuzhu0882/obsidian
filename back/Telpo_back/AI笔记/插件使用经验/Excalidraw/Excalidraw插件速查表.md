# Excalidraw插件速查表

> 相关笔记：[[AI笔记/插件使用经验/Excalidraw/Excalidraw插件使用指南]] · [[AI笔记/插件使用经验/Excalidraw/Excalidraw插件速查表]] · [[AI笔记/插件使用经验/Excalidraw/Excalidraw模板]]

## 1. 基本信息

- 名称：Excalidraw
- ID：`obsidian-excalidraw-plugin`
- 版本：2.22.1
- 作者：Zsolt Viczian
- 平台：桌面端 / 可能支持移动端
- 分类：可视化、图形与媒体

## 2. 你最应该先做的事

1. 打开设置页看插件选项
2. 打开命令面板搜索插件名称
3. 对照本地配置键确认当前 vault 已启用的能力
4. 结合同目录的模板页试用

## 3. 本地可见配置项

- `copyLinkToElemenetAnchorTo100`
- `copyFrameLinkByName`
- `disableDoubleClickTextEditing`
- `phoneFooterSafeAreaPadding`
- `folder`
- `cropFolder`
- `annotateFolder`
- `embedUseExcalidrawFolder`
- `templateFilePath`
- `scriptFolderPath`
