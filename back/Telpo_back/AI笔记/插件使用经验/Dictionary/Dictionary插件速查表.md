# Dictionary插件速查表

> 相关笔记：[[AI笔记/插件使用经验/Dictionary/Dictionary插件使用指南]] · [[AI笔记/插件使用经验/Dictionary/Dictionary插件速查表]] · [[AI笔记/插件使用经验/Dictionary/Dictionary示例页]]

## 1. 基本信息

- 名称：Dictionary
- ID：`obsidian-dictionary-plugin`
- 版本：2.22.0
- 作者：phibr0
- 平台：桌面端 / 可能支持移动端
- 分类：写作辅助与语言工具

## 2. 你最应该先做的事

1. 打开设置页看插件选项
2. 打开命令面板搜索插件名称
3. 对照本地配置键确认当前 vault 已启用的能力
4. 结合同目录的示例页试用

## 3. 本地可见配置项

- `getLangFromFile`
- `defaultLanguage`
- `normalLang`
- `shouldShowSynonymPopover`
- `shouldShowCustomContextMenu`
- `apiSettings`
- `partOfSpeechApiName`
- `advancedSynonymAnalysis`
- `useCaching`
- `folder`

## 4. 用例速览

- 查单词、释义和同义词
- 在阅读英文资料时快速取词

## 5. 信息来源

- `manifest.json`
- `data.json`
- manifest 未提供 helpUrl

## 6. 最小可用实践

- 先在测试笔记中验证插件基本行为
- 再决定是否要纳入正式工作流
- 若涉及代码块、模板或可视化页面，可直接参考同目录配套文档
