# QuickAdd插件速查表

> 相关笔记：[[AI笔记/插件使用经验/QuickAdd/QuickAdd插件使用指南]] · [[AI笔记/插件使用经验/QuickAdd/QuickAdd插件速查表]] · [[AI笔记/插件使用经验/QuickAdd/QuickAdd模板]]

## 1. 基本信息

- 名称：QuickAdd
- ID：`quickadd`
- 版本：2.12.0
- 作者：Christian B. B. Houmann
- 平台：桌面端 / 可能支持移动端
- 分类：查询、模板与自动化

## 2. 你最应该先做的事

1. 打开设置页看插件选项
2. 打开命令面板搜索插件名称
3. 对照本地配置键确认当前 vault 已启用的能力
4. 结合同目录的模板页试用

## 3. 本地可见配置项

- `choices`
- `inputPrompt`
- `persistInputPromptDrafts`
- `useSelectionAsCaptureValue`
- `devMode`
- `templateFolderPath`
- `announceUpdates`
- `version`
- `globalVariables`
- `onePageInputEnabled`

## 4. 用例速览

- 快速新建笔记和输入模板
- 通过命令面板执行自动化动作

## 5. 信息来源

- `manifest.json`
- `data.json`
- [官方说明页](https://quickadd.obsidian.guide/docs/)

## 6. 最小可用实践

- 先在测试笔记中验证插件基本行为
- 再决定是否要纳入正式工作流
- 若涉及代码块、模板或可视化页面，可直接参考同目录配套文档
