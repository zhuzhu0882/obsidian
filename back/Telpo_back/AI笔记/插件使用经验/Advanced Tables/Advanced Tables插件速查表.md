# Advanced Tables插件速查表

> 相关笔记：[[AI笔记/插件使用经验/Advanced Tables/Advanced Tables插件使用指南]] · [[AI笔记/插件使用经验/Advanced Tables/Advanced Tables插件速查表]] · [[AI笔记/插件使用经验/Advanced Tables/Advanced Tables模板]]

## 1. 基本信息

- 名称：Advanced Tables
- ID：`table-editor-obsidian`
- 版本：0.22.2
- 作者：Tony Grosinger
- 平台：桌面端 / 可能支持移动端
- 分类：编辑器与输入增强

## 2. 你最应该先做的事

1. 打开设置页看插件选项
2. 打开命令面板搜索插件名称
3. 对照本地配置键确认当前 vault 已启用的能力
4. 结合同目录的模板页试用

## 3. 本地可见配置项

- `formatType`
- `showRibbonIcon`
- `bindEnter`
- `bindTab`

## 4. 用例速览

- 频繁编辑 Markdown 表格
- 希望用快捷键快速新增或对齐单元格

## 5. 信息来源

- `manifest.json`
- `data.json`
- manifest 未提供 helpUrl

- 先在测试笔记中验证插件基本行为
